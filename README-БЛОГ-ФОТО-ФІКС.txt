ВИПРАВЛЕННЯ РЕДАКТОРА ФОТО БЛОГУ

1. Якщо FINAL-update.sql з попереднього пакета вже запускали в Supabase — повторно запускати НЕ потрібно.
2. Завантажте файли цього ZIP у GitHub із заміною старих.
3. Commit changes.
4. Дочекайтеся Vercel → Ready.
5. Відкрийте сайт/адмінку та натисніть Ctrl+F5.

У CMS блогу:
- «Показати повністю — без обрізання» = contain.
- «Заповнити блок» = cover.
- Висота 300 / 420 / 520 / 650 px тепер застосовується до фото.
- Позиція Верх / Центр / Низ застосовується при режимі cover.
- Налаштування використовуються і на сторінці блогу, і в самій статті.
