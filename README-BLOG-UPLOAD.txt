Завантаження фото/відео до блогу

1. Supabase → SQL Editor → запустити blog-storage.sql
2. GitHub → замінити:
   - admin.js
   - styles.css
3. Commit changes
4. Vercel → дочекатися Ready
5. CMS → Блог → Редагувати статтю
6. Натиснути «Вибрати фото з комп’ютера»
7. Вибрати JPG / PNG / WEBP
8. Натиснути «Завантажити фото»
9. Дочекатися «Фото завантажено ✓»
10. Побачити preview
11. Натиснути «Зберегти статтю»

URL фото підставляється автоматично.
Для відео працює так само.
