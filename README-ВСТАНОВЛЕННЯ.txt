ФІНАЛЬНЕ ОБ'ЄДНАНЕ ОНОВЛЕННЯ

Цей ZIP об'єднує зміни, щоб не завантажувати сайт двічі.

ЩО ВИПРАВЛЕНО
1. Прибрано з публічного сайту службові/технічні фрази:
   - «Ключові напрями ... з керуванням через CMS»
   - «Окремі сторінки ...»
   - «Повний перелік редагується в адмін-панелі»
   - «Інтерактивні матеріали ...»
   - «Медичний контент ...»
   - «30-секундні відео ...»
   - «Статті з заголовком ...»
   - «Нові відгуки проходять модерацію»

2. Оновлено SEO-сторінки:
   - пупкова грижа
   - пахова грижа
   - жовчнокам'яна хвороба
   - лапароскопічна хірургія
   - проктологія
   Canonical/OG URL тепер ведуть на поточний Vercel-домен.

3. robots.txt і sitemap.xml використовують:
   https://dr-makovetskyi-new.vercel.app/

4. Блог:
   - Enter і списки зберігаються.
   - Фото можна завантажувати з комп'ютера.
   - Додано редактор відображення фото:
       • показати повністю без обрізання (contain)
       • заповнити блок з можливим обрізанням (cover)
       • висота 300 / 420 / 520 / 650 px
       • позиція: верх / центр / низ
   - Налаштування працюють на головній та на сторінці статті.

ПОРЯДОК
A. Supabase → SQL Editor → запустити FINAL-update.sql ОДИН РАЗ.
B. Розпакувати ZIP.
C. GitHub → Add file → Upload files → завантажити ВСІ файли з ZIP, крім SQL/README за бажанням.
   Найважливіші файли для заміни:
   index.html
   admin.js
   app.js
   styles.css
   post.html
   post.js
   pupkova-gryzha.html
   pakhova-gryzha.html
   zhovchnokamiana-khvoroba.html
   laparoskopichna-khirurhiia.html
   proktolohiia.html
   sitemap.xml
   robots.txt
D. Commit changes.
E. Vercel → дочекатися Ready.
F. На сайті Ctrl+F5.

Примітка: admin.html також включений, щоб зберегти актуальну CMS з двома редагованими панелями.
